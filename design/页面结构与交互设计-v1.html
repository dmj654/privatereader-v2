私阅读 · 页面结构与交互设计

单机 iOS 小说 / 漫画阅读器。这一版只定义页面怎么分、元素放哪里、操作发生什么，不涉及视觉风格，也不含代码。

v1.1 改了什么：补上小说阅读器的朗读（边听边读）；把漫画阅读器从"一个灰框"重做成完整一节，含阅读模式、手势热区、设置项、话目录。上一版把听书列进"不做"是判断失误。

01设计前提

上一轮已确认的三件事，是这份设计的地基。任何页面如果违背它们，就是我设计错了。

内容来源
本地文件 + 在线书源
运行形态
iOS 原生 · 侧载安装
数据归属
全在本地 · 无账号

由此推导出的四条设计原则

  • 单手可达——所有高频操作放在屏幕下半部和右下角，拇指够得着。
  • 阅读优先——从主页到正文最多两次点击，从书架一次。
  • 离线不慌——没网时 App 不报错、不白屏，已缓存的内容照常读。
  • 坏一个不塌全局——在线书源按源隔离，某个源挂了只影响它自己。

04通用二级页面

详情、目录、书源管理——这三页小说和漫画共用。阅读器单独拆成下面两节，因为它俩压根不是同一种东西：一个是文字流，一个是图片流。

05阅读器 · 小说

文字流阅读器，全 App 工作量最大的一页。三个状态：干净正文态、菜单态、朗读中。默认是正文态——打开就是字，一条栏都没有。

朗读的六条规则

场景行为
开始朗读从当前页的第一句开始念，不从头念。你已经看到哪，它就念哪
跟随高亮按句切分，念完一句高亮下一句并自动滚动，保证那句始终在屏幕中上部
暂停 / 继续暂停时高亮停在原句不动，继续时从那一句的头半句接着念，不跳句
手动翻页你手动翻到别处，朗读立刻跟着跳过去，不跟你抢
章节结束自动接下一章继续念，中间不弹提示、不需要点确认
面板收起点屏幕中间收起面板，朗读不停、高亮继续跟随；再点一下面板原样回来
锁屏 / 切后台继续播放，锁屏界面显示书名和播放控制，回来位置不变
一个必须提前说的取舍：iOS 自带的朗读引擎（AVSpeechSynthesizer）免费、离线、免费用，但中文机械感明显；云端 TTS 自然得多，可是要联网、要钱、还可能把正文发到别人服务器上——对"全本地"的你来说这条不太合适。我默认用系统引擎，做得好不好听，取决于 iOS 的中文音色，这个后面可以先用真机听一耳朵再决定。

06阅读器 · 漫画

漫画不是"带图的文字"。它没有文字流可分页，要处理缩放、要处理几万像素的长图、还要考虑日漫的右开翻页。上一版我只画了一个灰框，等于没设计，这一节补全。

两种阅读模式

模式适合什么怎么翻
单页普通页漫，一屏一页左右滑或点击两侧翻页，双击放大看细节
条漫连续竖屏长图，国漫/韩漫大多数是这种上下连续滚动，没有"页"的概念，只有进度

默认按书源标记自动选模式，判断错了可以在显示设置里手动锁死——一本书锁死后，下次打开还是这个模式。

「双页」暂时不做：它必须横屏才成立，而横屏要多做一整套布局。先把竖屏的单页和条漫打磨好，双页留给后面。

手势与热区

左侧 1/3点一下 = 上一页
右滑 = 上一页
中间 1/3点一下 = 呼出 / 收起
菜单栏
右侧 1/3点一下 = 下一页
左滑 = 下一页

双指缩放 · 放大后单指拖动 · 双击复位 · 从左边缘右滑退出阅读器（任何模式下都成立）

漫画这边最容易做砸的三件事，先说在前面：一是长图拼接——高度算错就会滚到一半乱跳；二是翻页方向——日漫右开、国漫左开，搞反了整本书都得倒着看；三是缓存——一话几十张图，不预加载就会翻一页等一下，这个体验比小说差得远。这三块的工作量，比画这几个界面大得多。

07关键流程

四条最常走的路径，我按「点几下、中间会不会卡」的标准压缩过。橙色的是需要额外操作的节点。

A · 导入一本本地小说 3 步，不需要网络
书架右上 ＋→ 系统文件选择器可多选→ 解析中显示书名与进度→ 完成提示成功 N 本 / 失败 M 本→ 回到书架并高亮新书
B · 在线找一本书并开始读 从发现页算起 4 步
发现 · 选源→ 榜单 / 分类→ 书籍详情→ ＋ 加入书架默认进「在追」→ 继续阅读
C · 接着读 App 打开后 1 步到正文
打开 App→ 主页 · 接着读卡片→ 阅读器（直达上次位置）
D · 搜一个词，看它在哪 一个框出三类结果
点搜索框→ 输入（停 0.3 秒自动搜）→ 书架命中 / 各源命中 并行返回→ ＋书架 或 直接打开
另外有一个入口：在阅读器里长按选中文字，菜单里有「全书搜索这个词」，结果是一个带上下文摘录的列表，点一条直接跳到那一页。
E · 边听边读 开朗读 1 步，之后不用管
阅读器菜单→ 点 ♪→ 当前页第一句开始念 + 高亮跟随→ 章末自动接下一章→ 锁屏后仍在播
你在听的过程中随手翻页，朗读跟着跳；不想听了点暂停，高亮停在那一句，下次继续从那半句接着念。

08交互规则

这些是容易在实现时走偏的地方，先定死。

位置操作结果
书架封面单击进书籍详情（不是直接读）——因为详情页才有简介和目录
长按弹出快捷面板：改分组、标记已读完、导出、删除。面板从底部升起，不遮挡封面
右上角编辑进多选模式，可批量删除 / 批量分组。左上角出现「全选」，底部出现操作条
阅读器（小说）点左 1/3上一页；到本章第一页时提示「已是本章开头，上一章？」
点右 1/3下一页；到本章最后一页后自动进下一章
点中间 1/3切换控制层：普通阅读时是上下菜单栏，朗读中是朗读面板。正文不位移
左边缘右滑退出阅读器回书架，进度已保存，无确认弹窗
点右侧目录钮从左侧滑出目录抽屉（占屏宽 86%），右边留一条缝能看见正文；点遮罩或右滑关掉，回到原页
点右侧耳机钮进入听书：菜单面板换成朗读面板，正文位置不动；语速音色沿用上次
点顶栏「净化」开关当前书的正文净化，开启时文字变主色。规则跟着书源走，在书源管理里能看到命中的条目
点「退出」结束朗读，控制层从朗读面板切回普通菜单，正文留在当前位置
朗读时手动翻页朗读立刻跟着跳到你翻到的那页，不跟你抢位置
阅读器（漫画）点左 / 右 1/3上一页 / 下一页；到话尾自动进下一话，不停顿不确认
左右滑翻页。翻页方向按「右开 / 左开」设置走，方向反了整本书都是倒着看
双击在「适应整屏」和「放大 2 倍」之间切换，放大后双击回到整屏
双指缩放放大后单指拖动看图；拖到画面边缘继续滑才翻页，避免看图时误翻
条漫连续模式滑到倒数第 3 屏时预加载下一话，滚到底自动接上，不出现空白等待
搜索输入停 0.3 秒后并发请求；继续输入则取消上一次请求
单个源失败只在该分组内显示重试，其他结果照常展示，不弹全局错误
在线书籍打开未缓存章节边下边读，正文先到先显示，不等整章下完
离线时打开未缓存书明确提示「这一章还没缓存」，并列出已缓存的章节可跳到那里
删除书删除默认只删书架记录、保留缓存文件；第二次确认时才有「同时删除文件」开关
全局返回每个 Tab 各自记住自己的滚动位置，切回来不回到顶部

09状态清单

一个页面要设计四种样子：正常、空、加载、出错。这里把每个页面的另外三种先定下来，避免做到一半发现「空了显示什么」没想清楚。

页面空 / 首次加载出错
主页 一本书都没有：一句「书架还是空的」，两个按钮——「导入本地文件」「去发现找书」 本地数据读得快，不显示骨架；封面逐步浮现 封面文件损坏 → 显示默认占位图 + 书名文字，不显示破图
书架 同上；筛选后为空 → 「这个分组下还没有书」+ 一个「清除筛选」 首次启动若书多，先出占位格子再填封面 某本书解析失败 → 卡片标灰显示「无法打开」，点击给原因
发现 还没导入任何书源 → 整页替换成一个引导块：「导入第一份书源规则」，不显示空的榜单框架 榜单区域骨架屏，分类立刻可点 当前源挂了 → 顶部一条横条「星空书源暂时不可用，换个源」，不挡住下面的分类
搜索 没输入：显示搜索历史 + 最近读的三本书；历史为空则显示「搜书名、作者，或书里的任何一句话」 每个源独立骨架，书架结果先出 全部源都失败 → 一句「所有书源都没响应」，附「检查网络」「换个源」两个动作
阅读器 空章节（源站还没更新）→ 留在当前章末，提示「本章后暂无内容」 在线章节：先显示已取到的部分，底部一条细进度 章节取不到 → 保留当前页不动，弹一条可关闭的提示，不跳走、不白屏
朗读 从没点过 ♪ → 第一次点就从当前页第一句开始，不需要选章节、不需要从头 切音色 / 首次合成有零点几秒延迟，播放键转圈，正文照常可看 系统没装中文语音包 → 明确提示「去系统设置下载中文语音」，不静默失败
阅读器（漫画） 整话图片全挂 → 「本话加载失败」，两个动作：重试、换源 先出模糊占位图再逐张替换，不整屏空白；滚动时提前加载后面几屏 单张图失败 → 原位留占位并自动重试 2 次，不打断阅读；连续失败才弹提示
导入 — 逐个文件显示进度，可取消 格式不支持 / 文件加密 → 列在结果页，写清哪个文件、为什么失败

10决定清单

悬着的四件事全部落地了，现在没有待确认项。下面是全部结论，做的时候照着走。

已定
书架默认封面墙 3 列，可切列表视图。单一本书的信息量（封面 + 进度）比书名更重要。
已定
小说默认左右翻页，漫画默认整页翻页；条漫源自动切上下滚动。三种都能在设置里改。
已定
「接着读」跳过详情页，直接进上次位置。详情页只在你想看简介或换章时才进。
已定
分组预设「在追 / 看完 / 弃了」，可自建分组。在线新书默认进「在追」。
已定
删除书默认只删记录，保留缓存文件；要删文件得二次确认。防止手滑丢书。
已定
备份做成一个文件（.zip），含书架清单、进度、书签、书源配置；缓存文件可选是否包含。
已定
朗读进 V1：小说阅读器内置系统 TTS，逐句高亮跟随，章末自动接下一章，锁屏可控。上一版我把它砍掉了，是错的。
已定
漫画阅读器单独设计，两种模式（单页 / 条漫），模式按书保存，换书不互相影响。不做横屏双页——它必须横屏才成立，留着以后再说。
已定
书源用「开源阅读」(legado) 的格式。不做规则编辑器，也不做「贴网址自动生成」——社区里现成的 JSON 直接导入，一个文件常常打包几十个源，坏的单独关掉。
已定
阅读统计要做。主页那张「本周时长」卡片保留，点开是一个轻量统计页：本周 / 本月时长、读完几本、日均多久。不单开 Tab。
已定
朗读音色用本地系统语音。不联网、不花钱、正文不出手机。代价是中文音色偏机械，先把功能跑通，音质以后再说。

书源这条连带出来的三件事

用 legado 的格式，省掉了自己发明一套规则语法的工作，但有三处要跟着改：① 书源管理要能拆包——一个 JSON 导入后展开成几十个源，逐个开关；② 净化规则是书源自带的，顶栏那个「净化」开关才有真实内容，不是摆设；③ 书源改版失效是常态，所以每个源要有「测一下」按钮，坏了自己关掉，不影响其他源。

这张图之外的边界，我这一版故意没碰：分享扩展（从 Safari / 文件 App 直接分享进本 App）、iPad 布局、iCloud 同步、云端 TTS、漫画横屏双页、漫画润色特效（自动分格、跨页拼接矫正）。

另外要更正一句：上一版我把「听书」列进了不做清单，这是我没问清你的阅读习惯就下的判断。现在朗读已经回到 V1，并且是核心功能，不是附加项。
确认这份结构后，下一步是：把线框做成可点击的高保真原型（iOS 上直接试手感），再定视觉，最后才写代码。
